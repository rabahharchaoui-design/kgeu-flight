# PLAN.md: Pocket Flight Sim work queue

Worked top to bottom by the orchestrator (see PROMPT.md). One item at a time. Mark items [x] with a one line note when done. Session blocks have their own tag, branch, report, and merge gate.

General rules for every item: iOS Safari landscape only, 60fps target on iPhone, tilt controls stay removed, reuse existing systems (radio clip pipeline tools/make_radio.py, explosion pools, airport lighting, records and achievements, touch controls and menu from the UX session).

Modes: the two player modes are EASY and HARD. Always say Easy and Hard in the game and in docs (never Rookie or Pilot). In code they are still stored and tested as SKILL 'rookie' (Easy) and 'pilot' (Hard), with rookie() true in Easy, so saved installs keep their choice. Every run is tagged with runMode(): a run flown in Easy at any moment counts as Easy.
